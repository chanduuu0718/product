# Affiliate Product Portal

A lightweight affiliate product publishing portal with a public code-based product page and an admin dashboard.

## Planned structure
- Public product lookup: enter a product code and view the product without login.
- Product gallery: up to 4 swipeable images.
- Product details: name, price, original price, description and offer information.
- Buy Now: redirects through the stored affiliate URL.
- Admin: create, edit, publish, hide and delete products.

## Development
This repository contains the initial product portal implementation scaffold. See \`docs/ARCHITECTURE.md\` for the design decisions and next integration steps.
